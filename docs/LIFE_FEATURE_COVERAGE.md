## Newly clarified in this audit

- The remedies page now has a distinct **Basic Mantra & Daily Practices** section. Existing catalog entries such as prayer/reflection, gratitude/discipline, meditation, and transparent seva remain optional, non-coercive, multilingual, and separate from personalized rules.
- `approvedRemedyRules` remains empty. No chart-specific remedy is activated.
- No PDF implementation was added because the repository has no existing PDF library or report endpoint; adding a static or fabricated report would violate the requested evidence boundary.
- Advanced features without a documented convention and deterministic evidence remain explicitly unsupported or review-required.
- Phase 1 browser QA (2026-10-19) verified all three sections with a calculated selected profile at 320×844, 390×844, and 1280×844. Moon house numbering showed Moon in house 1; all twelve Bhava cards and actual aspect rows rendered; profile identity appeared in the three sections; English/Hindi/Hinglish titles changed correctly. Page horizontal scroll stayed at zero after a programmatic horizontal scroll attempt, while a wide planetary table remained internally scrollable. This is UI/software evidence, not independent calculation validation.
- Legal and assistant implementation status (2026-10-19): legal documents are separate pages in English, Hindi, and Hinglish; signup requires explicit versioned acceptance, and older accounts receive a re-acceptance prompt before using question-history endpoints. Rule-based assistant answers are generated server-side from a selected saved chart; both profile ownership and exact birth date/time/timezone/coordinates are checked against the chart before answering. Question records are owner-scoped, paginated, searchable/filterable, idempotent on retry and individually deletable. The new PostgreSQL migration is additive and non-destructive. No migration or database integration run occurred because the guarded test runner found no `LIFE_TEST_DATABASE_URL`; therefore persistent storage, foreign-key deletion behavior and acceptance timestamps are not database-verified. The privacy copy honestly notes that account-level deletion/export and a general privacy-request contact form are not implemented. Browser checks covered the legal pages and logged-out assistant at 320, 360, 375, 390, 430, and 1280 CSS-pixel viewport widths; no page-level horizontal overflow or browser page errors were observed. Authenticated question submission and history persistence were not browser-tested without a disposable database.
