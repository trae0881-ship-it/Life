# Remedy Rule Source-Review Worksheets

These worksheets are evidence-gathering records, not approvals. A book listing,
search result, secondary summary, or general statement that a practice exists is
not verification of the exact remedy passage or its chart-eligibility rule.

No candidate below is source-verified, approved, or active. Do not fill an
approval decision from memory or inference. Preserve the source edition and
review evidence with the reviewer’s record.

## Human-review decision protocol

The reviewer must independently inspect the source passage, complete all fields,
record the decision as `APPROVE`, `REJECT`, or `RETURN FOR EVIDENCE`, and sign/date
the record. `APPROVE` is allowed only when the implementation record is complete,
the source passage is verified, safety review is complete, and fixtures pass.
Until then, the code registry `approvedRemedyRules` must remain empty.
